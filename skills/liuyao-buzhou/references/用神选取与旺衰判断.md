# 六爻核心密码：用神的选取与旺衰判断

> **核心要义：** 用神不当则全盘皆错，旺衰不辨则应期难推 —— 此为六爻进阶之基石

---

## 一、用神：卦象的轴心与灵魂

用神是所测之人事物在卦中的象征点。如同射箭之靶，一切生克冲合、旺衰动静皆围绕用神展开。

> "用神者，所用之事神也。或用父母，或用妻财，或用官鬼，或用子孙，或用兄弟，各随所测而取。"
> —— 《增删卜易》

### 用神双重属性

| 属性 | 说明 |
|------|------|
| 代表性 | 将现实问题映射到六亲体系 |
| 指向性 | 所有吉凶判断最终归于用神 |
| 互动性 | 用神与日月、动爻构成生克网络 |
| 时效性 | 旺衰随月建更替而流转 |

## 二、用神选取法则：六亲定位与通变

### 基本选取规则

| 预测类别 | 用神六亲 | 细化场景 |
|----------|----------|----------|
| 功名事业 | 官鬼爻 | 官职、升迁、女测婚姻 |
| 财运投资 | 妻财爻 | 钱财、货物、男测婚姻 |
| 文书学业 | 父母爻 | 考试、合同、长辈、房屋 |
| 子嗣生育 | 子孙爻 | 儿女、晚辈、医药、平安 |
| 兄弟朋友 | 兄弟爻 | 同辈、竞争、破财阻隔 |
| 自身安危 | 世爻 | 自身吉凶、疾病主症 |

### 复合取用实例（测买房）

| 维度 | 用神 | 说明 |
|------|------|------|
| 房产本身 | 父母爻 | 房屋质量、位置 |
| 资金压力 | 妻财爻 | 贷款、存款 |
| 交易过程 | 官鬼爻 | 中介、手续 |

**核心法则：** 以父母爻为主要用神，兼看财爻官爻。若父母旺而财破，房好却买不起，反之亦然。

### 进阶心法

测多人事时，确立"主用神"与"辅助用神"。

例如出行测安全：
- 主用神：世爻
- 辅助用神：子孙爻（平安）

两者皆旺方为吉。

## 三、旺衰判断：日月动爻的三重影响

用神旺衰取决于：**月建之令、日辰之权、动爻之变**。三者交织形成五大状态。

### 旺衰状态说明

| 状态 | 条件 |
|------|------|
| 旺 | 月生日辰扶、动爻来生助 |
| 相 | 月建当令、得日辰生扶 |
| 休 | 月建克耗、日辰持平 |
| 囚/死 | 月破日冲、受动爻克 |

### 日月对用神的作用权重

- **月建：** 司一月之权，决定用神"月令状态"
  - 生用神则旺，克用神则衰
  - 月破之爻（月建冲用神）为极衰

- **日辰：** 为六爻之主，管辖"当日旺衰"及生克权
  - 日生用神为暗动增力
  - 日克用神为受制
  - 日辰可合可冲，能解月破，也能破合

### 旺衰量化口诀

```
>3处生扶 → "旺"
>2处生扶 → "相"
>1处生扶或持平 → "休"
无生且受克 → "囚"
月破日冲、动爻群克 → "死"
```

## 四、用神旺与过旺判断条件

衡量爻的旺度有以下条件（占以上任何一条以上者，即可按旺相论）：

1. 临月建（测长期人事尚需考虑临太岁）
2. 临日建（测眼下人事尚需考虑临时辰）
3. 得月建生、扶
4. 得日建生、扶
5. 明动、暗动
6. 动而化进
7. 动化回头生
8. 得动爻之生、扶
9. 在合局内得生，或得合局之生
10. 有气而势众，虽休囚而不受克

**过旺标准：** 用神同时占1、2、6（或7）、8四条以上者，即为过旺。

## 五、实战精析：用神组合与应期密码

### 💹 求财卦例

**卦例：** 寅月戊午日，测某项目利润。得妻财子水动化申金（回头生），月建寅木耗子水，但日辰午火冲子水（暗动），且化申金生扶。

**解析：** 用神虽被月耗，但得日冲暗动、动化回头生，旺相有力。

**断语：** 财可求，但需耐心，待申金当令之期（申月或申日）进账。

**反馈：** 申月资金到账。

### ⚕️ 疾病卦例

**卦例：** 辰月乙卯日，自测旧疾复发。世爻酉金临月建辰土之生，日辰卯木冲酉（日破），且卦中动爻午火克世。

**解析：** 用神受月生得日破，日破减力五成，又受动爻午火克。原神未土被卯日合住无法救。

**断语：** 病情短期难愈，午日需防加重。

**结果：** 午日症状明显加剧，后经调整用药，戌月方缓。

### 旺衰与应期对应表

| 用神状态 | 应期特征 | 应期范围 |
|----------|----------|----------|
| 旺相逢生扶 | 近期可成，逢值或逢合 | 当日、本周 |
| 休囚待旺时 | 需待补旺之日月 | 月后、季内 |
| 月破日冲 | 破而逢合，冲中逢合 | 填实之月、日 |
| 动爻制用 | 制神入墓、逢合时 | 制神休囚时 |

### 断应要点

- 用神旺则应期近，用神衰则应期远
- 用神受克，应期在克神受制之时
- 用神逢合，应期在冲合之日

## 六、专业命理师的用神审视流程

1. **定用神** — 按事类取六亲，多事象则分主次
2. **观日月** — 查月建生克、日辰生克冲合，定旺衰基数
3. **察动爻** — 看原神、忌神、仇神是否发动，形成何种链条
4. **断组合** — 三合、六合、反伏吟等特殊格局对用神的影响
5. **推应期** — 综合旺衰与动变，锁定应事时间窗口
